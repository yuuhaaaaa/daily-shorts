# 30초 대본 구조

| 구간 | 시간 | 역할 | 비트 수 |
|---|---|---|---|
| 훅 | 0~3초 | 숫자 하나 또는 질문 하나. 0프레임에 이미 글자가 보여야 한다(썸네일) | 1 |
| 전개 | 3~22초 | 왜 그런지, 얼마나인지. 비트마다 새 정보 1개 | 5~7 |
| 반전·정리 | 22~27초 | "그래서 지금은?" | 1~2 |
| 행동 | 27~30초 | 시청자가 할 일 하나 | 1 |

- 비트 하나는 2~4초, 1~3줄, 줄당 12자 이내.
- 강조어(`emphasis`)는 비트당 최대 1개, 그 줄에 그대로 들어 있어야 한다.

## script.json 형식

```json
{
  "date": "2026-10-30",
  "slug": "weather-whiplash",
  "topic": "10월 기온 급변",
  "category": "weather",
  "accent": "#FF5A1F",
  "beats": [
    {"lines": ["10월인데", "29.6℃"], "emphasis": "29.6℃", "duration": 3, "style": "slam"}
  ],
  "sources": [
    {"claim": "서울 29.6℃, 10월 중순 최고기온 경신", "url": "https://..."}
  ],
  "title": "40자 이내 제목 #Shorts",
  "description": "설명 2~3줄 + 출처",
  "hashtags": ["#Shorts", "#날씨"]
}
```

`style`: `slam` | `rise` | `split`. 생략하면 `rise`.
