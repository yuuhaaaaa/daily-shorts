# 검사 항목

`scripts/check.py`가 자동으로 검사한다. 사람이 볼 항목은 별도 표시.

## 대본 (`check.py script`)
| 항목 | 기준 | 수준 |
|---|---|---|
| 총 길이 | 28~32초 | 오류 |
| 훅 | 첫 비트 3초 이하 | 오류 |
| 비트 길이 | 2~4초 | 오류 |
| 비트 수 | 7~12개 | 경고 |
| 줄 수 | 비트당 1~3줄 | 오류 |
| 줄 길이 | 12자 이내 | 오류 |
| 강조어 | 해당 비트의 줄 안에 있음 | 오류 |
| 출처 | 숫자가 하나라도 있으면 sources 1개 이상, URL은 http(s) | 오류 |
| 제목 | 40자 이내, 본문에 있는 말만 | 오류(길이) / 사람(내용) |
| 해시태그 | 3~5개, `#Shorts` 포함 | 오류 |
| 금지어 | `역대급`, `충격`, `무조건` 등 channel.md 금지 표현 | 경고 |
| 중복 | 최근 14일 history에 같은 slug·topic 없음 | 오류 |

## 영상 (`check.py video`)
| 항목 | 기준 | 수준 |
|---|---|---|
| 파일 | `short.mp4` 존재, 0바이트 아님 | 오류 |
| 길이 | script 총 길이 ±0.5초 | 오류 |
| 해상도 | 1080×1920 | 오류 |
| 스냅샷 | 0초, 15초, 29초 프레임에 글자가 보이고 잘리지 않음 | 사람 |

## 업로드 전 (`upload.py`)
| 항목 | 기준 |
|---|---|
| 승인 | `APPROVED` 파일 존재 |
| 하루 1편 | history에 같은 날짜 업로드 없음 |
| 상태 | run_daily 상태에서 check·verify가 done |
